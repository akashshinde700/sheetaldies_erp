# Composition brief — SVT ERP

## Objective
Use latent-spaces/brag and HyperFrames to make a short, practical visual introduction to the ERP. This is a preview, not the requested complete hands-on training.

## Output
- `composition/` and `brag.mp4`; landscape 1920 × 1080, 23 seconds.
- LOOK: warm off-white `#f5f3ef`, charcoal `#26221e`, app blue `#075985`, amber `#d97706`; Inter/system sans; clean, restrained industrial UI, real screenshots; no abstract filler or fabricated performance claims.

## Source
- `frontend/index.html`, `frontend/src/index.css`, `frontend/src/components/Sidebar.jsx`, `frontend/src/App.jsx` and feature pages.
- `composition/assets/screens` contains actual Playwright captures with synthetic empty API data and a fictional Demo tool. Authentication is a development bypass. The mock-data disclosure must be visible throughout.
- Storyboard and beats are in `brag-plan.md`.

## Audio
- `assets/music/bed.mp3`: Happy Beats / Business Moves Vol. 10 by Sascha Ende, ende.app, CC BY 4.0. Low volume, gentle fade-out; no voiceover. Cut timings guided by bundled `music-cues` in latent-spaces/brag. SFX intentionally omitted so UI text remains primary. Audio-reactive extraction omitted because the helper was unavailable.
